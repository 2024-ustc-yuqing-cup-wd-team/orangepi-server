# IMAP reader example

A small, read-only IMAP client that prints the subjects, senders, dates and a
short preview of the most recent messages in a mailbox. It exists to show how to
talk to a mail server **without hard-coding credentials**: everything is read
from environment variables.

## Setup

```bash
cd examples/imap-reader
cp .env.example .env     # fill in host, user and app password
npm install
npm start
```

`npm start` uses Node's built-in `--env-file` support (Node.js 20.6+), so there
is no `dotenv` dependency.

## Configuration

| Variable | Default | Meaning |
| --- | --- | --- |
| `IMAP_HOST` | — | Mail server, e.g. `imap.qq.com` or `imap.gmail.com` |
| `IMAP_PORT` | `993` | Port; 993 for TLS |
| `IMAP_TLS` | `true` | Use TLS |
| `IMAP_USER` | — | Mailbox account |
| `IMAP_PASSWORD` | — | App password / authorisation code |
| `IMAP_MAILBOX` | `INBOX` | Folder to read |
| `IMAP_UNSEEN_ONLY` | `true` | Only list unseen messages |
| `IMAP_LIMIT` | `10` | Maximum number of messages to print |

## Security notes

- Use an **application password** (or an IMAP authorisation code) generated by
  the mail provider. Do not use your account password, and do not commit either.
- `.env` is ignored by git. If a credential is ever committed, revoke it in the
  mail provider first — deleting the file is not enough, because it stays in the
  git history.
- This example only reads. It never marks messages as read, moves or deletes
  anything.
